# Security Policy

## Supported Versions

Currently, only the latest version of the SDK receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

Please **do not report security vulnerabilities through public GitHub issues, discussions, or pull requests!**

Instead, please report them to **security@cleverreach.com**.

We will acknowledge receipt of your vulnerability report, verify the issue, and work on a patch as quickly as possible. Once the issue is resolved and a patch is released, we will inform you.
